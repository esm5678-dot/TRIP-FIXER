# TRIP FIXER 최종 설계와 현장 준비

서울에서 대기나 휴관을 만난 외국인 여행자가 지키려는 경험과 다음 약속을 입력하면, 하이커 그라운드 2·3층 또는 청계천 광교 입구에서 다음 행동 하나를 제안한다. 설치·실행은 [프로젝트 시작 안내](../../README.md), 설계 검토는 아래 순서로 진행한다.

| 확인할 것 | 문서 |
|---|---|
| 누구의 어떤 문제를 풀며 화면·서버·데이터가 무엇을 책임지는가 | [개발 설계와 요구사항별 인수 기준](ENGINEERING-DESIGN-KO.md) |
| 앱, 사용자, 운영 자료와 모델이 어디서 연결되는가 | [시스템 구조도](architecture.svg) · [데이터 흐름도](flow.svg) |
| 왜 이 언어·모델·오픈소스를 골랐는가 | [기술 선택표](TECHNOLOGY-KO.md) · [사용 부품 목록](../sbom.cdx.json) |
| 대회장에서 누가 무엇을 만들고 언제 검수하는가 | [14시간 현장 제작과 인계](FIELD-GUIDE-KO.md) |
| 공개 주소에서 어떤 기대값과 실제 결과를 확인했는가 | [배포 시연 검수](VERIFICATION-KO.md) |

대표 장면은 14:50에 들은 2층 대기 45분과 15:30 정문 약속이다. 사진이 목표인 여행자는 3층에서 이용 가능 여부를 묻고, 꼭 무대 영상이 필요한 여행자는 복귀 또는 목표 수정을 선택한다. 여행자가 직원에게 들은 대기는 해당 체험과 해당 여행에만 적용한다.

리허설의 실행·검증 기록은 본선에서 새로 작성할 범위를 정하는 근거로 활용한다. 사전 문서 참고 범위는 운영진 안내를 확인한다. [리허설 앱](https://trip-fixer-rehearsal.vercel.app) · [검수한 실행 코드](https://github.com/esm5678-dot/TRIP-FIXER/tree/4caabaab944bc4a86e1445e566e282e2e3a41f76)

### 여행자 화면 언어

상단에서 **English · 日本語 · 简体中文 · Français** 중 하나를 고른다. 목표 입력, 결과, 대기·휴관 사유, 복귀 안내와 직원 질문의 뜻이 선택한 언어로 표시된다. 직원에게 보여주는 문장은 한국어로 유지한다. 언어를 바꿔도 작성 중인 선택과 여행 기록이 유지된다. 같은 브라우저에서는 다음 방문에도 마지막 언어가 적용된다.
