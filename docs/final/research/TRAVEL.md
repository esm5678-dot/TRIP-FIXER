## 현장에서 한 번에 확인할 예시

금요일 14:50에 2층 무대에서 45분 대기를 들었고 15:30에 정문으로 돌아와야 한다. 대기만 해도 15:35다. 단체 사진이 목적이면 3층을 **현장 확인**으로 제시한다. 무대 영상이 필수이면 후보가 없다. 새로 5분 대기를 들으면 이전 보고를 교체하되 이동·체험·복귀가 미확인이면 계속 현장 확인으로 표시한다. 이때 실시간 운영이 복구됐다는 공지는 생성하지 않는다.

이 예시는 합성 시연 입력이다. 실제 관광객 선택률, 만족도, 실시간 대기 API 제공 여부의 근거로 쓰지 않는다.
