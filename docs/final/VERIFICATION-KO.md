# TRIP FIXER 공개 배포 검수 결과

2026년 11월 26일 13:49~13:50 KST에 [공개 리허설](https://trip-fixer-rehearsal.vercel.app)에서 실제 Chromium 데스크톱 1365×900과 모바일 크기 390×844로 확인했다. 대상 배포 ID는 dpl_wt3p12vo1WVzxTZjhpWsjQiy7Cgc다. 독립 과제마다 새 브라우저 컨텍스트를 사용했고, 새로고침은 동일 탭에서 시험했다. 사용자가 입력한 시연용 대기·약속으로 결과를 재현했다.

| 독립 브라우저 과제 | 실제 결과 |
|---|---|
| 사진 목표, 2층 대기 45분 | 15:35 시작은 15:30 정문 약속을 넘긴다고 표시했다. 3층 포토존을 현장 확인 상태로 제안했고, 직원에게 보여줄 한국어 질문이 열렸다. |
| 위 결과에서 새로고침 후 여행 종료 | 3층과 정문 약속이 복원됐다. 종료하면 탭의 저장 항목 수가 0이 됐다. |
| 꼭 2층 무대 촬영, 같은 45분 | 같은 목표 후보가 없다고 표시하고 약속 장소 검색을 제공했다. |
| 모바일에서 건물 전체 휴관, 변경 취소 | 전체 휴관으로 후보가 사라졌고 취소하면 무대가 복원됐다. 가로 넘침이 없었다. |
| 청계천 산책, 무계단 필수 | 검수한 광교 입구에 계단이 있다는 이유와 후보 없음 상태를 표시했다. |
| 영어 메모 해석 불가 | 수동 목표 버튼으로 이어가 실제 결과를 받았다. 실패의 내부 원인과 실모델 품질·비용은 이 응답에서 확정할 수 없다. |

공개 API 요청 8건도 기대값과 일치했다. 기본 분기 5건에 더해 다음 시간 경계를 확인했다.

1. 14:50에 들은 40분 대기가 15:30 약속과 정확히 맞닿으면 체험 시간이 없어 후보에서 제외됐다.
2. 데모의 현재 시각 14:50을 고정하고 14:39의 40분 대기와 15:19 마감을 주어 11분 경과를 재현했다. 새 대기 보고가 없으므로 제외가 유지됐다.
3. 같은 상태에서 새 대기 5분을 보고하면 이전 관측이 교체되어 무대가 현장 확인 상태로 돌아왔다.

독립 배포 검수 결과는 브라우저 6/6, API 8/8이다. 별도로 해당 코드의 GitHub Actions에서 단위 시험 28개와 브라우저·HTTP 시험 7개가 통과했고 빌드·타입 검사·SBOM 생성과 보관도 성공했다.
